# 👨‍💼 Employee Management System

A Java-based Employee Management System designed to manage basic employee information.

## 🚀 Features

- Add employees
- View all employees
- Search employees by ID
- Store employee names
- Store employee salaries
- Menu-driven interface
- Supports up to 100 employees

## 🛠️ Technologies Used

- Java
- Arrays
- Scanner
- Loops
- Conditional statements
- Switch statements
- Object-oriented programming concepts

## ▶️ How to Run

1. Clone this repository.
2. Open `EmployeeManagementSystem.java` in NetBeans, VS Code, or another Java IDE.
3. Compile the program.
4. Run the program.
5. Follow the menu instructions.

## 📋 Main Menu

1. Add Employee
2. View Employees
3. Search Employee
4. Exit
